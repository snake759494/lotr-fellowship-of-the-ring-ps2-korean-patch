# 반지의 제왕: 반지 원정대 PS2 북미판 한글 패치 v1.1

SLUS-20520 북미 원본용 정식 한글 패치입니다. 첨부 파일은 xdelta 하나이며 원본 ISO·게임 파일·폰트는 제공하지 않습니다.

- 메뉴·설정·도움말·퀘스트·아이템·이야기 내레이션 UI 433항목과 대사 자막 1,008종 한글화.
- v1.1: 동영상 5편(인트로·호비튼·트롤 숲·바람마루·안두인 등)의 영어 음성에 한글 자막 추가, 카메라 좌우 조작 반전.
- 1바이트 글꼴 엔진에 2바이트 한글 출력 추가. 메뉴는 서울한강 EB, 대사는 나눔스퀘어 네오 Bold.
- 원본/완성/패치 SHA-256, 적용 방법, 제한과 재빌드는 저장소 README를 확인하세요.
- PCSX2에서 부팅·메뉴·새 게임·이야기 화면·플레이·일시정지 메뉴·컷신 자막 확인, 공개 소스 재빌드 및 xdelta 복원 해시 일치. 전체 플레이, 저장/불러오기, 대형 레벨 메모리 여유, 실기는 미검증입니다.
